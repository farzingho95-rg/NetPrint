# NetPrint: پرینت با پرینترهای تحت شبکه از اندروید

## روش‌های پیدا کردن پرینتر
- **Bonjour/mDNS**: سرویس‌های `_ipp._tcp`، `_pdl-datastream._tcp`، `_printer._tcp`
- **اسکن عمیق شبکه**: اسکن کل ‎/24 روی پورت‌های 631 (IPP)، 9100 (RAW) و 515 (LPD)
- **وارد کردن دستی IP**

## پروتکل‌های چاپ
- **IPP** (اکثر پرینترهای جدید، AirPrint/IPP Everywhere): فایل PDF، و اگر قبول نکرد application/octet-stream
- **RAW / JetDirect 9100** (HP و اکثر پرینترهای لیزری): فایل خام، متن ساده مستقیم
- **LPD/LPR** (پرینترهای قدیمی و پرینت‌سرورها)
- **دیالوگ چاپ سیستمی اندروید**: از افزونه‌های Mopria/HP/Canon/Epson استفاده می‌کند و پرینترهایی را هم پوشش می‌دهد که فرمت اختصاصی (PCL/PWG raster/...) می‌خواهند

## فرمت فایل‌ها
PDF، عکس (به PDF تبدیل می‌شود)، متن (روی RAW/LPD به صورت مستقیم، روی IPP به صورت PDF). از منوی Share بقیه اپ‌ها هم کار می‌کند.

## بیلد
پوشه را در Android Studio باز کنید (Gradle wrapper را خودش می‌سازد) و Run بزنید. minSdk 24، targetSdk 34.

## محدودیت‌ها
- پرینترهای ارزان GDI/host-based که فقط با درایور ویندوز کار می‌کنند با «چاپ مستقیم» جواب نمی‌دهند؛ برای این‌ها از «System print dialog» و افزونه سازنده استفاده کنید.
- IPPS (رمزنگاری TLS) هنوز پیاده نشده است.
